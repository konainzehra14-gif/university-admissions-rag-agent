# University Admissions Guide — RAG Chatbot

An AI-powered chatbot that answers general questions about university
admissions in Pakistan (eligibility, entry tests, deadlines, documents,
merit lists, scholarships) using Retrieval-Augmented Generation.

⚠️ **Generic guidance, not official advice.** The seed data in this repo is
general/illustrative. Admission rules, tests, and deadlines vary by
university and change every year — always verify on the official
university/HEC/IBCC/NTS website before relying on an answer.

## 🔹 Key Features
- 🎓 RAG-based question answering, grounded in your own documents
- 🔎 Hybrid BM25 retrieval with keyword boosting and two-stage re-ranking
- ⚡ Groq API for fast LLM responses
- 💬 Interactive multi-session chatbot built with Streamlit (with voice search & Urdu translation)
- 🗂️ Chat history and university directory built right into the main view
- 📚 Answers cite which source document they came from

## 🛠️ Tech Stack
Python · Streamlit · BM25 Okapi · Groq API · PyMuPDF

## Project structure
```
university-admissions-rag-chatbot/
├── app.py                    # Streamlit UI (multi-session chat, tools, voice, translation)
├── agent.py                  # Tool-calling agent logic
├── rag_engine.py             # Retrieval (BM25) + Groq LLM call logic
├── tools.py                  # Tool definitions (KB retrieval, merit calculator, web search)
├── ingest.py                 # Builds the BM25 search index from knowledge_base/
├── knowledge_base/           # Put your admissions guides/prospectuses here
│   └── admissions_guide.txt  # SAMPLE generic seed data
├── index/                    # Generated by ingest.py (chunks.pkl, metadata.pkl, tokens.pkl, keywords.pkl)
├── requirements.txt
├── .env.example
└── .streamlit/
    └── secrets.toml.example
```

## 1. Setup

```bash
git clone <your-repo-url>
cd university-admissions-rag-chatbot
python -m venv venv
source venv/bin/activate    # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Add your real knowledge base

Replace or add files inside `knowledge_base/` with real content: a specific
university's prospectus, HEC circulars, entry-test guides, merit-list PDFs
— as `.pdf`, `.txt`, or `.md` files.

## 3. Get a Groq API key

Sign up free at https://console.groq.com/keys, then either:

- **Local dev:** copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` and paste your key in, or
- **Streamlit Cloud:** paste the configuration into your app's **Settings → Secrets** on Streamlit Cloud.

## 4. Build the index

Run this once, and again any time you update the knowledge base:

```bash
python ingest.py
```

This reads everything in `knowledge_base/`, chunks it, and saves the token/keyword index files into `index/`.

## 5. Run the app

```bash
streamlit run app.py
```

Open the local URL Streamlit prints (usually http://localhost:8501).

## 6. Deploy to Streamlit Cloud

1. Push this repo to GitHub (include `knowledge_base/` and the generated
   `index/` folder so the deployed app doesn't need to re-run ingestion).
2. Go to https://share.streamlit.io, connect your GitHub repo, set the main
   file to `app.py`.
3. Add `GROQ_API_KEY` under **Settings → Secrets**.
4. Deploy.
